WEEK 2 SUBMISSION — EXPLORATORY DATA ANALYSIS AND VISUALIZATION

Dataset:
Titanic — Machine Learning from Disaster

Input:
titanic_cleaned.csv (prepared during Week 1)

Files:
1. Week2_Exploratory_Data_Analysis_and_Visualization_Report.docx
2. week2_eda.py
3. titanic_cleaned.csv
4. charts/ (six EDA visualizations)
5. requirements.txt
6. README.txt

How to run:
1. Install Python 3.10+.
2. Open Command Prompt/PowerShell in this folder.
3. Run: pip install -r requirements.txt
4. Run: python week2_eda.py

The script prints dataset structure, summary statistics, survival rates by sex and class,
and generates the six charts used in the report.
